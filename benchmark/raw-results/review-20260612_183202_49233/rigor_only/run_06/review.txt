## Review

**Leakage prevention — outstanding.** Every planted trap is caught:
- `account_status` is correctly identified as target-derived (`"closed"` iff `churned==1`), dropped from features (`src/data.py:26`, `split_xy` excludes it), and *quantified* via a leak probe showing ROC-AUC=1.0 — turning the trap into evidence.
- `StandardScaler` is inside the `Pipeline` and `.fit()` is called per-fold (`src/experiment.py:79-80`), so it never sees test data. A dedicated test (`test_preprocessing_fit_per_fold_no_global_leak`) enforces this.
- Exact duplicates (200 rows) are removed *before* splitting (`load_clean`, `src/data.py:53-54`), guarded by `test_dedup_happens_before_split`.
- The temporal column is handled deliberately: `TimeSeriesSplit` over rows sorted by `signup_date`, with explicit forward-chaining justification; the date is used only to order, never as a feature.
- Label-shuffle check collapses to ~0.5, confirming no residual leak.

**Methodology — strong.** Trivial baseline present (`DummyClassifier`, ~0.50). Metrics appropriate for 27% imbalance (ROC-AUC primary, PR-AUC, Brier — accuracy never read in isolation). Single-variable design: identical features/preprocessing/splits/seed, only the estimator differs. Paired Wilcoxon across folds. Both models use sklearn defaults with *zero* tuning on either side — fair, and honestly disclosed as "compares default-configured estimators, not tuned ones."

**Reproducibility — excellent.** Seed=7 fixed and logged in `metrics.json` config; environment block records Python version and git rev. Re-running from clean state produced byte-identical output (git stayed clean).

**Claims discipline — excellent.** Reports a null result and refuses to declare a winner. The "overlap" heuristic is conservative, and the report transparently surfaces the tension (all 5 folds favor LogReg, Wilcoxon p=0.062) rather than hiding it, letting the reader judge. Limitations are candid: small non-i.i.d. fold sample, synthetic near-linear data favoring the linear model, no tuning. No claim exceeds what the code measured.

**Executability — verified.** `pytest` → 10 passed. `make_dataset.py` + `run_experiment.py` ran clean and reproduced the committed REPORT.md numbers exactly.

**Code quality — high.** Clean `src`/`tests` separation, dataclasses for auditable stats, thorough docstrings explaining *why* each decision exists, no dead code. All five declared dependencies are used (`scipy` for Wilcoxon, `pytest` for the rigor tests).

Minor notes (not faults): n=5 time folds gives rough variance, but this is explicitly acknowledged; the synthetic generator is admittedly linear-friendly, also disclosed.
