## Summary

This is an exemplary, rigor-first experiment. Every planted trap in `make_dataset.py` (leaky `account_status`, 200 straddling duplicates, temporal `signup_date`) is correctly identified, handled, and *demonstrated* — not just asserted.

**Leakage prevention (excellent).** `account_status` is dropped as target leakage (`data.py:24,67`) and its leak is proven empirically: the leakage-ceiling check re-includes it and gets ROC-AUC = 1.000 (`metrics.json:34-37`). The scaler lives inside a `Pipeline` that is `clone()`d and fit per-fold on training rows only (`experiment.py:84-92`) — true split-before-transform. Exact duplicates are removed with `drop_duplicates()` *before* any split (`data.py:57`), confirmed n=200 removed. The temporal column is handled deliberately: rows ordered by `signup_date` and evaluated with `TimeSeriesSplit` so the future never trains on the past (`data.py:62`, `experiment.py:86`).

**Methodology (strong).** Trivial baseline present (`DummyClassifier(strategy="prior")` → 0.500). Class imbalance (churn 0.271) acknowledged; ROC-AUC/PR-AUC are headline, not accuracy. Both arms are library defaults at equal (zero) tuning budget — the single variable is model family. Plus a label-shuffle null check (AUC → 0.516) and a "real model beats floor but isn't near-perfect" test. *Minor weakness:* the paired CI uses the 1.96 normal multiplier on n=5 dependent (expanding-window) folds; a t-multiplier would be more honest. The conclusion still holds under t₄ (half-width ≈ 0.0125 < |−0.018|), so it doesn't change the verdict.

**Reproducibility (excellent).** Seed=17 fixed and logged, config + per-fold metrics written to `results/metrics.json`, git rev recorded, and re-running produced byte-identical outputs.

**Claims discipline (strong).** Report claims LR edges out GBM, backed by 5 folds with mean±sd and a paired interval, and is candid about limitations (weak signal, n=5, non-independent folds understating uncertainty, no tuning, single dataset). *Mild tension:* the conclusion leans on "interval excludes zero → LR outperforms" while the limitations say "we make no significance claim" — the winner framing is slightly firmer than the dependent-fold data robustly supports, though heavily hedged.

**Executability (excellent).** `pytest` → 11 passed; `python3 run_experiment.py` runs and auto-generates the dataset if absent; deps declared in `pyproject.toml`.

**Code quality (strong).** Clean, well-documented, no dead code, deps all used. Trivial nit: a couple of in-function imports (`clone`, `load_with_leak`).
