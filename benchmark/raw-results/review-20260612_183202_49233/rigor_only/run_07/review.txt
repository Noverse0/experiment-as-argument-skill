## Review

**Leakage prevention — exemplary.** `account_status` is identified as a target leak (closed iff churned), dropped, *and* proven so with a leakage-ceiling sanity check that adds it back and shows ROC-AUC → 1.0 (`src/data.py:79`, `src/experiment.py:187`). The `StandardScaler` is inside the `Pipeline`, so it's fit on the train fold only (`src/experiment.py:36`). The 200 planted exact duplicates are dropped *before* splitting (`src/data.py:62`), preventing train/test straddle. The temporal column is handled deliberately: rows are sorted by `signup_date` and evaluated with `TimeSeriesSplit` (train=past, test=future), with an explicit justification. A label-shuffle check confirms the pipeline collapses to ~0.5 with no residual leak.

**Methodology — strong, with two minor blemishes.** A trivial majority baseline (DummyClassifier, AUC 0.5) is present; metrics are ROC-AUC + PR-AUC, appropriate for the 27% positive rate (not accuracy); both arms are untuned (equal zero tuning budget). However: (1) the LR arm carries `class_weight="balanced"` while GB does not, so the arms differ by slightly more than the single stated variable (acknowledged in code comments). (2) The paired t-test is run over 5 `TimeSeriesSplit` folds, whose training sets are nested/overlapping — the independence assumption of the t-test is violated, so the p-value is optimistic. The report flags low power but not this validity issue.

**Reproducibility — excellent.** Seed (7) fixed and logged; full config + per-fold metrics + provenance (data sha256, git rev, sklearn/python versions) written to `results/metrics.json`. Re-run reproduced results bit-for-bit; `test_determinism` enforces this.

**Claims discipline — good and notably honest.** The report declares a winner (LR, p=0.017) but heavily and honestly qualifies it: one dataset/one seed, low n, varying fold sizes, no tuning, and — most impressively — that the linear-in-log-odds synthetic DGP structurally favors logistic regression. That last caveat essentially undercuts its own winner claim with integrity. The main reservation: stating "Logistic regression is better" as a significant result rests on correlated folds and a single synthetic dataset, which is somewhat stronger than the evidence cleanly supports.

**Executability — verified.** `pytest` (13 pass) and `python3 run_experiment.py` both work from the existing state; tests self-generate the CSV if missing. Fast (<5s each).

**Code quality — high.** Clean module separation, dataclasses, thorough docstrings documenting the leak surface, no dead code, dependencies declared in both `requirements.txt` and `pyproject.toml` and all used (scipy in `paired_delta`).
