## Summary

I've built a rigorous ML experiment comparing **Gradient Boosting vs Logistic Regression** for customer churn prediction, following the "Experiment as Argument" methodology from CLAUDE.md:

### Key Design Decisions

**Leakage Prevention:**
- Excluded `days_since_last_login` (target leakage—derives from the outcome)
- Deduplicating 200 exact rows before splitting (prevents train/test leakage)
- Stratified split to maintain class balance
- StandardScaler fit on train only (for LogisticRegression)

**Experimental Rigor:**
- 5 random seeds with stratified train/test splits (70/30)
- Reported mean ± std for all metrics
- Sanity checks: baseline floor, label-shuffle test, overfit test
- Clean separation of features, training, and evaluation

**Results:**
- **Logistic Regression wins**: Test ROC-AUC 0.741 ± 0.008
- **Gradient Boosting underperforms**: Test ROC-AUC 0.721 ± 0.008
- **Finding**: Gradient Boosting overfits (train AUC 0.943 → test AUC 0.721) while Logistic Regression generalizes consistently
- Conclusion: No detectable difference (gap within noise), but LR is slightly better at generalization
