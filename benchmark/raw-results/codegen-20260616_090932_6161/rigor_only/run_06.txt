## Experiment Overview

**Claim:** On the customer churn dataset, does gradient boosting outperform logistic regression when using only legitimate features?

**Key Design Decisions:**
- **Target leak detection & removal:** Identified and excluded `days_since_last_login` as a target leak (churned customers inherently have high values recorded after the outcome)
- **Data discipline:** Deduplicated before splitting (200 exact duplicates), stratified train/test split (70/30), fit scaler on train only
- **Variance estimation:** 3 independent runs with seeds [7, 42, 123]
- **Sanity checks:** Label-shuffle test, baseline comparison, metrics on legitimate features only (tenure_months, monthly_spend, support_tickets)

**Results:**
- **Logistic Regression ROC-AUC:** 0.7478 ± 0.0029
- **Gradient Boosting ROC-AUC:** 0.7335 ± 0.0090
- **Conclusion:** No detectable difference; logistic regression is simpler and preferred
