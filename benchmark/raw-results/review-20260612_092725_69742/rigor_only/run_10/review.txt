## Review

**Leakage prevention — strong.** The headline trap (`account_status`, which is `"closed"` iff churned) is explicitly excluded with a documented rationale. The 200 planted exact duplicates are dropped *before* the split (4200→4000, verified independently), so they cannot straddle train/test. `StandardScaler` is fit on train only and applied to test — verified by `test_scaler_fitted_on_train_only`. The one soft spot: `signup_date` is temporal but a random stratified split is used. This is acknowledged as a deliberate trade-off in the limitations, so it meets the "explicit justification" bar, though a time-based split would have been more rigorous.

**Methodology — adequate.** ROC-AUC is the primary metric with F1/precision/recall/accuracy reported — not accuracy alone, appropriate for the 27% churn rate. A majority-class baseline is computed (0.729) and both models clear it (barely, on accuracy; clearly on AUC). Tuning budget is symmetric: both models use fixed defaults, no search for either. Weaknesses: only 3 random splits (not real CV folds, though the report calls them "folds"), and the `label_shuffle_test` is largely theater — it trains on random `X` with shuffled `y`, which doesn't exercise the real pipeline and proves little about leakage.

**Reproducibility — good.** Seeds fixed (0,1,2), metrics written to `results/metrics.json`, re-run is byte-identical. Minor gap: the config (hyperparameters, num_seeds, seeds) is not logged alongside the metrics — only the aggregate numbers are persisted.

**Claims discipline — strong.** The report self-reports **LOW** confidence, states the −0.0026 AUC difference is "within noise margins," and refuses to crown a winner. Variance (±std over 3 runs) is reported for every metric. Limitations are honest and specific. The CI logic (1.96·std with n=3) is statistically loose, but it errs conservative, which is the right direction.

**Executability — excellent.** `pytest` → 14 passed in ~2s; `python run_experiment.py` completes in seconds and regenerates artifacts.

**Code quality — solid.** Typed, documented, clean structure. Minor: unused imports (`json`, `Path`) in `run_experiment.py`; `roc_curve`+`auc` used where `roc_auc_score` would be direct; the dead-weight `label_shuffle_test`. All declared dependencies are used.
