## Summary

This is a rigorous experiment. All three planted traps are correctly defused, results are bit-for-bit reproducible, and the report is honest about what it can and cannot conclude.

**Leakage (strong).** `account_status` is dropped in `clean_data` (`src/data.py:6,19`) and a dedicated test asserts it never survives prep. Deduplication runs *before* the split (`prepare` order: clean → dedup → feature_engineer → time_split), and the run confirms "removed 200 exact duplicates (4200 → 4000)" — so the planted duplicates can't straddle the split. The temporal column is handled deliberately via a sort-by-`signup_day` time split rather than a random one. Critically, the `StandardScaler` lives *inside* the sklearn `Pipeline`, so `cross_validate` refits it per fold and `final_eval` fits it on train only — no transform leakage. A label-shuffle sanity test (AUC 0.519) and a leakage-ceiling guard back this up.

**Methodology (good).** Trivial majority-class baseline present (AUC 0.5000). Metrics are appropriate for the ~27.6% churn rate — ROC-AUC primary, plus F1/precision/recall, not accuracy alone. Both models share the same (untuned) budget, honestly disclosed. One real defect: in `run_experiment.py:61-64`, `pipelines_per_seed` is dead code, and `cv_metrics` reuses a single pipeline built with `seed=SEEDS[0]` — so across the "3 seeds" only the `StratifiedKFold` shuffle varies; the model's `random_state` stays fixed at 42. The 15 observations measure fold variance, not seed-of-model variance, so the "[42, 7, 123] seeds" framing slightly overstates the diversity (immaterial for deterministic LR, real for GB).

**Reproducibility (excellent).** Seeds fixed and logged, config + per-fold values written to `results/metrics.json`, a determinism unit test exists, and I verified a fresh run is byte-identical to the committed metrics.

**Claims (strong).** The report claims "no detectable difference," not a winner — backed by n=15 folds with std and an overlap check. Limitations are unusually honest (untuned, single synthetic dataset whose DGP is logistic and structurally favors LR, no formal significance test, temporal-cohort caveat). Minor gap: GB's hold-out AUC (0.607) collapses versus its CV AUC (0.723), a notable train/test shift that's only implicitly covered by the "most recent cohort" note rather than flagged directly; and the ±1-std overlap rule is statistically weak (though disclosed).

**Executability (excellent).** `pytest` → 22 passed; `python3 run_experiment.py` completes in seconds and writes both artifacts.

**Code quality (good).** Clean module separation; requirements declared and used. Dead code (`pipelines_per_seed`) and misleading comments at `run_experiment.py:61-64`; no README documenting commands (REPORT.md and a usage docstring partially compensate).
