This is essentially a model answer for leakage.

**Methodology — real weakness.** Trivial baseline (majority class, 0.75 = base rate), label-shuffle, and overfit-tiny sanity checks are all present, and metrics are imbalance-appropriate (AUC primary plus balanced-acc/precision/recall/F1). The replication protocol provides no actual variance estimate — it's `n=1` dressed as `n=3`.

The report never notices that its own zero variance is a determinism artifact. Limitations are otherwise honest and the headline number is plausibly low (no implausible-AUC problem).
