## Summary

**Leakage (the central test): caught cleanly.** The disguised leak `days_since_last_login` is dropped and explicitly justified as recorded post-outcome (`src/preprocessing.py:48-51`, REPORT limitations #5). The scaler is fit on train only (`FitOnTrainScaler`), duplicates are removed *before* splitting (so they can't straddle), and `signup_date` is dropped with an explicit justification. The label-shuffle sanity check returns F1≈0.029 (near zero), confirming no leak. The honest AUC lands at ~0.73 — exactly the "honest features" range, not the suspicious ~0.95 a leaked run would show. This is essentially ideal handling of the v2 trap.

**The serious problem is report/claims integrity.** The committed `REPORT.md` did **not** match the committed `results/metrics.json`:
- Committed report: n=1, seed 42 only, LR=0.700 / GB=0.750, "**Gradient Boosting shows a modest advantage** (+0.050)".
- Committed metrics: 3 seeds, LR=0.335±0.029 / GB=0.346±0.047, diff +0.010 — *not significant*.

Root cause: two tests (`test_save_results_creates_files`, `test_report_generated_with_conclusion`) call `save_results()`, which hardcodes `Path("REPORT.md")` (CWD = repo root, ignoring `output_dir`) and writes **fabricated fixture values** (0.7/0.75) over the real report. I confirmed this — running a single test clobbers the project's REPORT.md. So the shipped report was a test artifact claiming a winner the real data doesn't support.

When run correctly, the entrypoint's own logic is honest: it regenerates "**No significant difference detected**" (n=3). But even the honest report contains **hardcoded sanity-check prose that doesn't match reality**: "Majority class rate ~57%" (actual 72.95%), "shuffle F1 ~0.45" (actual 0.029), "target rate ~43%" (actual ~27%). These are fixed narrative strings, not measured values.

**Other findings:** 12/12 tests pass; entrypoint runs in seconds; deps declared/used. Baseline is only printed (a majority predictor gives F1=0, so it's a weak floor); no time-based split despite the temporal column; 3 seeds is modest; no config file capturing hyperparameters.
