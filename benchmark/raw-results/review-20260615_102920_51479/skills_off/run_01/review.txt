## Review

This is a strong, rigorous experiment that **caught the disguised v2 leak**. I verified the planted trap against `make_dataset.py`: `days_since_last_login` is generated conditionally on the churn outcome (gamma mean ~44 days if churned vs ~8 if not), making it a post-outcome target leak behind a plausible feature name.

**Leakage (central test) — caught cleanly.** `src/data.py` defines `LEAKY_FEATURES = {"days_since_last_login"}` and drops it, with a code comment giving the correct *temporal* reasoning ("recorded after the churn outcome because a churned customer has stopped logging in"). REPORT.md repeats this justification explicitly. The resulting AUC is ~0.73 on honest features, not the inflated ~0.95 the leak would produce. Supporting discipline is all present: scaler inside a Pipeline fit on train only (verified by `test_scaler_fits_on_train_only`), 200 exact duplicates removed *before* the split, temporal split on `signup_date` chosen deliberately and justified over a random split, and label-shuffle + overfit-tiny sanity checks that gate the run.

**Methodology — solid.** Majority-class baseline (0.5), ROC-AUC + Average Precision + F1 for the 27% imbalance (not accuracy alone), and identical zero-tuning budget for both arms. 5-fold CV × 3 seeds = 15 evals each. The gap-vs-noise comparison uses a crude "pooled noise" (mean of stds), not a paired test or proper standard error — adequate but approximate (and they admit it).

**Reproducibility — verified.** Dataset seed (7) and CV seeds (42,43,44) fixed, config/metrics written to `results/metrics.json`. Re-running reproduced the stored numbers exactly.

**Claims — honest, one small gap.** Conclusion "no detectable difference" is drawn from CV and backed by the gap-vs-noise figure; limitations are thorough and the report notices that including the leak would inflate AUC. Weakness: the held-out test shows GBM 0.60 vs LR 0.73 — a 0.13 gap that goes unreconciled against the "no difference" headline. It's gestured at via the "cohort shift" limitation but not directly addressed.

**Executability — works.** 13 tests pass; `python run_experiment.py` completes in ~7s with output matching the report. One defect: `pyproject.toml` declares `build-backend = "setuptools.backends.legacy:build"`, which doesn't exist (should be `setuptools.build_meta`) — `pip install -e .` would fail, but the declared run commands don't depend on it.

**Code quality — clean.** Well-separated modules, documented, no dead code, deps declared and used. The broken build-backend is the only blemish.
