## Summary

**Claim tested:** Gradient boosting outperforms logistic regression for churn prediction.

**Key design decisions:**
- **Deduplication** before split (removed 200 exact duplicates)
- **Time-based split** (70% earliest → train, 30% recent → test) respects temporal structure
- **Feature selection** excludes the target leak (`days_since_last_login`); uses only: tenure_months, monthly_spend, support_tickets
- **Rigorous evaluation**: 5 different seeds, StandardScaler fit-on-train-apply-to-test, sanity checks (baseline floor, class balance, label shuffle, overfit test)
- **Full experiment runtime**: ~2.5 seconds (well under 5 minutes)
