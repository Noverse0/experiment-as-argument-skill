## Review: Churn Prediction — GB vs LR

This is a genuinely rigorous experiment that correctly identified and defused every planted trap. It runs clean, reproduces exactly, and draws an honest, appropriately hedged conclusion.

### Leakage prevention — strong
- **`account_status` correctly dropped** as target-derived label leakage (`src/data.py:11`, `LEAKY_COLS`), with explicit justification in REPORT and a dedicated test (`test_no_leaky_columns`).
- **Scaler fitted train-only**: `StandardScaler` lives inside a `Pipeline` (`src/models.py`), so it is refit on each CV training fold and on train-only for the final fit — never on test. There is even an explicit test asserting this (`test_scaler_fitted_on_train_only`).
- **Duplicates removed before splitting** (`drop_duplicates(subset=features+target)`), so the 202 planted exact-dup rows cannot straddle the split.
- **Temporal split** by `signup_date` rather than random — the deliberate choice for time-ordered data.
- Baseline floor + label-shuffle ceiling sanity checks are built in.

Minor: dedup on the feature+target subset (not full row) removed 202 vs the 200 planted — a couple of natural feature/target collisions were dropped too; defensible since such rows are indistinguishable. Minor: the positional time split leaves 9 records sharing the boundary date `2024-12-21` straddling train/test — a small same-day leak (signup_date isn't a feature, so impact is negligible).

### Methodological validity — strong
Majority-class baseline present; ROC-AUC chosen as primary metric for the 27% imbalance, with F1/precision/recall reported (not accuracy alone); both arms use identical preprocessing/split and zero tuning (equal budget); 3 seeds × 5-fold CV (n=15) with reported std. The winner rule (`|gap| > max(std)`) is an honest but ad-hoc heuristic rather than a paired statistical test. The label-shuffle uses a **single** permutation and returns 0.636 — a noisy single draw treated as a binary pass/fail; a proper null would average many shuffles.

### Reproducibility — excellent
Seeds fixed and logged (`SEEDS=[42,123,777]`, CV `random_state`, model `random_state`); config + metrics written to `results/metrics.json`; re-running reproduced all metrics identically (only the UTC timestamp changed), and `make_dataset.py` regenerates the CSV byte-identically (same md5).

### Claims discipline — strong, with one tension
The conclusion ("no detectable difference, gap −0.0128 within noise 0.0184") is backed by 15 CV scores with variance and is appropriately hedged. The limitations section is honest (single-seed final test, no tuning, temporal proxy, small feature set, synthetic data). **However**, the Sanity Checks table reports the label-shuffle as "✗ FAIL — suspect leakage," yet the conclusion proceeds to a clean result without ever addressing that flagged contradiction — the report states a value its own narrative flags as a problem but never resolves it.

### Executability — excellent
`pytest` → 15/15 passed in ~2s. `python3 run_experiment.py` runs end-to-end in seconds, writes both artifacts, and the entrypoint gives a clear remediation message if the CSV is missing.

### Code quality — strong
Clean modular split (`data`/`models`/`evaluate`), docstrings and type hints, no dead code, all declared dependencies used. Runs cleanly on sklearn 1.7 despite `>=1.3` pin.
