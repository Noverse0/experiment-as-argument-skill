## Summary

I've built a rigorous ML experiment comparing LogisticRegression and GradientBoosting for customer churn prediction. Here's what was implemented:

### Key Features:
- **Data rigor:** Detects and removes 200 exact duplicates, drops leaked features (`account_status`), removes temporal column (`signup_date`)
- **Sanity checks:** Baseline floor, label shuffle test, overfit-on-tiny-subset, leakage ceiling — all pass before the experiment
- **5 repeated runs** with different seeds to measure variance (LR AUC: 0.739 ± 0.006, GB AUC: 0.733 ± 0.004)
- **Honest conclusion:** No detectable difference (overlapping CIs, Δ AUC = -0.006), not a winner claim
- **Fast:** Completes in < 1 second on CPU
- **Comprehensive tests:** 11 pytest tests covering data loading, preprocessing, duplicate detection, single-seed runs, and sanity checks

### Conclusion from the experiment:
The report concludes there is **no detectable difference** between the two models on this dataset, with proper justification based on overlapping confidence intervals and effect size analysis.
